# 上架指南（到 awesome-dsh-plugin 插件市场）

> 现状：插件代码、打包、安装、加载全部验证通过（见 `docs/验证记录.md`）。
> 剩下三步都需要**你自己的 GitHub / npm 账号**，代码侧已经全部准备好。

## 0. 前置

- 一个 GitHub 账号（以下简称 `<owner>`）
- 一个 npm 账号（免费注册：https://www.npmjs.com/signup）
- git（本机已装 2.56.0）

---

## 1. 建 GitHub 仓库并推送

在 GitHub 网页新建**空仓库** `dsh-self-learn`（不要勾 README / .gitignore），然后在 `D:\工作\dsh-workspace\plugins\dsh-self-learn` 执行：

```bash
git remote add origin https://github.com/<owner>/dsh-self-learn.git
git branch -M main
git push -u origin main
```

推送后在仓库 **About → Topics** 里加 `dsh-plugin`（市场要求，缺了会被 CI 打回）。

然后改 `package.json`，在 `"license": "MIT",` 后面加一行（npm 发布后市场靠它把包和仓库关联起来）：

```json
  "repository": { "type": "git", "url": "https://github.com/<owner>/dsh-self-learn" },
```

改完提交：

```bash
git add package.json && git commit -m "chore: add repository field" && git push
```

> 仓库要**满 1 天**才能被收录（CI 自动按创建时间判断）。今天建、明天提 PR 正好。

---

## 2. 发 npm 包（推荐，不强制）

```bash
npm login          # 浏览器里登录一次
npm publish        # 包名 dsh-self-learn，若被占用可改成 @<你的npm名>/dsh-self-learn
```

验收：

```bash
npm view dsh-self-learn version
```

看到 `0.1.0` 即成功。

> 若提示 `402 Payment Required`：说明用了别人的私有 scope，改成无 scope 的名字，或换 `@你的用户名/dsh-self-learn`（同时改 `package.json` 的 name，并同步下文条目里的 `name`）。

---

## 3. 提 PR 到 awesome-dsh-plugin（收录＝上架）

1. Fork：https://github.com/awesome-dsh-plugin/awesome-dsh-plugin
2. 在你的 fork 里新建**一个文件** `data/plugins/<owner>__dsh-self-learn.yml`，内容用 `market/owner__dsh-self-learn.yml` 这份模板，把两处 `<owner>` 换成你的 GitHub 用户名：

```yaml
url: https://github.com/<owner>/dsh-self-learn
name: <owner>/dsh-self-learn
category: tools
description:
  en: Turns Bilibili videos and live streams, web pages and local files into a daily learning loop - local ffmpeg and faster-whisper transcription, zero-token heuristic digests of about 1.5 KB, five-section notes with an index, and a resident live recorder.
  zh: 把 B 站视频与直播、网页、本地文件变成每日学习闭环：本地 ffmpeg + faster-whisper 转写，启发式摘要约 1.5KB，五段式笔记与索引，外加常驻直播录制。
```

3. 提交并发起 PR（标题随意，例如 `Add dsh-self-learn`）。CI 会检查：

   - `package.json` 里有 `dsh.bundle`（✅ 已有）
   - 仓库满 1 天
   - YAML 格式、分类合法
4. 合并后官网与市场目录自动重建，`dsh` 的 **Plugins → Discover** 里就能搜到。

---

## 4. 装到自己的 profile 里用（不等上架也能装）

本地路径装（推荐先这样用）：

```bash
dsh plugin --profile web add "D:\工作\dsh-workspace\plugins\dsh-self-learn"
```

或从打包文件装：

```bash
dsh plugin --profile web add "D:\工作\dsh-workspace\plugins\dsh-self-learn\dsh-self-learn-0.1.0.tgz"
```

装完重启 DSH，工具 `learn_status / learn_add / learn_digest / learn_note / learn_live` 就出现了。

---

## 5. 首次配置

1. 准备 python（已有可复用）：`D:\工作\dsh-workspace\.tmp-asr\Scripts\python.exe`
2. 编辑 `%USERPROFILE%\.dsh\self-learn\config.json`：

```json
{
  "enabled": true,
  "python": "D:\\工作\\dsh-workspace\\.tmp-asr\\Scripts\\python.exe",
  "model": "small",
  "rooms": [
    { "id": "4199783", "name": "马上淋雨" },
    { "id": "26897779", "name": "果冻橙橙君" }
  ],
  "segmentSecs": 1800
}
```

3. 自检：`node "%USERPROFILE%\.dsh\self-learn\..\..\..\plugins\dsh-self-learn\scripts\doctor.mjs"`（或进插件目录跑 `node scripts\doctor.mjs`）
