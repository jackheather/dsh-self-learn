# 上架指南（dsh-self-learn）

分三段：**GitHub 仓库** → **npm 发布** → **awesome-dsh-plugin 目录 PR**。
前两段做完后，别人就能用 `dsh plugin add dsh-self-learn` 装；第三段做完才会出现在 DSH 的插件市场里。

---

## 0. 前置（一次性）

| 前提 | 检查命令 | 期望 |
| --- | --- | --- |
| Node ≥ 20 | `node -v` | v20+ |
| npm 已登录 | `cmd /c npm whoami` | 你的用户名 |
| git 已登录 GitHub | `gh auth status` | Logged in to github.com |
| 本机 `github.com` 可访问 | `curl -s -o NUL -w "%{http_code}" https://github.com/` | `200` |

> 本机 DNS 把 github.com 解析到 `20.205.243.166`（443 不通）。可用 `node dsh-evolution\\scripts\\gh-proxy.mjs` 起本地 CONNECT 代理（127.0.0.1:7899，只改写 github.com），再用 `$env:HTTPS_PROXY="http://127.0.0.1:7899"`。

## 1. GitHub 仓库

```powershell
cd D:\\工作\\dsh-workspace\\plugins\\dsh-self-learn
gh repo create dsh-self-learn --public --source . --remote origin --push
gh repo edit --add-topic dsh-plugin --add-topic dsh
```

要求（awesome-dsh-plugin 的硬门槛）：

- 仓库是 public；
- 加 topic `dsh-plugin`；
- 仓库创建满 1 天才可提交目录 PR（可先准备，到点再提）；
- `package.json` 的 `repository` 必须指回该仓库：

```json
"repository": { "type": "git", "url": "git+https://github.com/<owner>/dsh-self-learn.git" }
```

## 2. npm 发布

```powershell
cd D:\\工作\\dsh-workspace\\plugins\\dsh-self-learn
cmd /c npm pack            # 先看包里有什么（应含 src/ scripts/ skill/ cordis.patch.yml）
cmd /c npm publish --access public
```

常见错误：

- `E403 ... Two-factor authentication or granular access token with bypass 2fa enabled is required to publish packages`
  → 在 npmjs.com 生成 **Classic → Automation** token（或 Granular 勾 bypass 2FA），然后：
  `cmd /c npm config set //registry.npmjs.org/:_authToken=<token>`
- `ENEEDAUTH` → 没登录：`npm login --auth-type=web`（会打印一个 URL，浏览器里完成后回车）
- `402 Payment Required` → 包名已被占用，改 `name` 或加 scope（`@jackheather/dsh-self-learn`）

发布后自检：

```powershell
cmd /c npm view dsh-self-learn version
dsh plugin --profile web add dsh-self-learn   # 真装一次
```

## 3. 提交到插件市场目录（awesome-dsh-plugin）

市场索引是 `https://awesome-dsh-plugin.com/plugins.json`，收录方式=**一个 PR 加一个文件**：

`data/plugins/<owner>__<repo>.yml`

```yaml
name: dsh-self-learn
url: https://github.com/jackheather/dsh-self-learn
category: tools
description:
  en: "Learn from Bilibili videos, web pages, local files and live streams: auto ASR + OCR + digest, returning only ~1.5KB summaries and saving 90%+ tokens."
  zh: "从 B 站视频、网页、本地文件、直播里学习：自动转写 + 画面 OCR + 摘要，每次只回约 1.5KB，省 90% 以上 token。"
```

可选字段：`icon`（仓库内图片路径或 URL）、`tarball`（默认走 npm）。

PR 要求：

1. 只加这一个文件，不要动别的；
2. 描述必须和代码实际能力一致（不能吹没实现的功能）；
3. `category` 从目录允许值里选，本插件用 `tools`；
4. CI 会校验 YAML 字段与 npm 包是否存在。

## 4. 本地安装（给自己用）

```powershell
# 开发装（link，改代码即时生效）
dsh plugin --profile web add D:\\工作\\dsh-workspace\\plugins\\dsh-self-learn
# or npm 装
dsh plugin --profile web add dsh-self-learn
```

> `desktop` profile 被 Electron 独占（`profile "desktop" is managed exclusively by the Electron application`），CLI 装不进去；桌面端用界面里的 Plugins 面板装，或装到 `web` profile 后在浏览器里用。
