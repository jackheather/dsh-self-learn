# AI 自主学习插件 · 使用规则（给 Agent）

> 目标：用最少的 token 持续学习。规则只有四条。

## 1. 先看状态，别乱读文件

```
learn_status
```

只读这一行输出。不要 ls 数据目录，不要一次读多篇笔记。

## 2. 一次只处理一个来源

```
learn_digest <来源 id>      # 唯一值得读进上下文的文本，约 1.5KB
```

- 摘要带时间戳。只有某句看不懂、或明显缺上下文时，才回原文查那一段（用 grep，不整篇读）。
- 绝不把 `transcripts/*.txt` 整篇读进上下文。

## 3. 读完立刻写成五段笔记

```
learn_note source=<id> title=<标题> oneLine=<一句话>
  mechanisms=[…] actions=[…] quotes=[…] doubts=[…] [creed=…]
```

- 一句话 ≤80 字；机制 3–8 条；动作要能打勾；原话 1–3 条。
- 值得长期守的，才加 `creed`。
- 写完不要回读笔记文件，工具会告诉你路径。

## 4. 直播交给守护，不要在对话里盯

```
learn_live start rooms=4199783,26897779
learn_live status
```

录制与转写全在本地，token 0。只在收到「某段转写完成」时，按第 2 步读摘要。

## 反模式（会烧 token）

- 把 30 分钟直播原文整篇读进来总结。
- 为了"完整"把 10 条视频的转写一次性塞进上下文。
- 每轮都 `learn_status` + 读最近三篇笔记。
- 用模型去抽字幕/做 ASR（本地 ffmpeg + whisper 已经做了）。
